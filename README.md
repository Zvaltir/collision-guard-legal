# Collision Guard for Jira Cloud

Collision Guard warns you when another user updates the Jira work item you currently have open.

## How it works

Open a Jira work item normally. If another user updates that work item while you have it open, Collision Guard displays a warning so you can reload before continuing.

Your own changes and comment-only updates do not trigger a warning.

## Configuration

None. Collision Guard works automatically after installation.

## Limitations

Collision Guard does not lock work items, merge concurrent edits, or guarantee prevention of conflicting changes.
